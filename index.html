First time installing a Forge mod?Installation guide +
  1. Set up Minecraft 1.8.9. Install Java 8 and Forge 1.8.9-11.15.1.2318 using the links in the Vibe installation instructions.
  2. Add Vibe. Download a published Vibe mod JAR and place it in your Minecraft game directory's mods folder. If no release is available yet, follow the repository's build instructions.
  3. Launch and explore. Start the Forge profile. Press Right Shift to open ClickGUI.
